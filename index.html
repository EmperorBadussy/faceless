// Pipeline

How It Works

Three-stage GPU pipeline. Detect. Align. Swap. All in real-time.

01

Face Detection

RetinaFace neural network detects faces in the video stream with sub-pixel precision landmarks.

02

Feature Alignment

68-point landmark alignment maps source face geometry to target for precise overlay positioning.

03

Neural Swap & Blend

InsightFace model performs the swap with color correction and seamless edge blending.
